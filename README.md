# Audible Data Cleaning & Standardization

## 📌 Project Overview

This project focuses on cleaning and standardizing an Audible audiobook dataset using Microsoft Excel Power Query.

The objective was to transform inconsistent and unstructured data into a cleaner, analysis-ready format by applying various Power Query transformations.

## 🛠️ Tools Used

- Microsoft Excel
- Power Query

## 🎯 Data Cleaning Tasks

The project covers the following transformations:

1. Standardized book title casing
2. Separated combined author names into multiple columns
3. Checked and standardized release date format
4. Converted text-based time duration into a structured duration format
5. Cleaned price values and handled errors
6. Converted text-based star ratings into numeric values
7. Separated narrator names into multiple columns
8. Combined release date and language into a `releaseinfo` field
9. Applied the appropriate data type to the price column

## 🔧 Power Query Techniques Used

- Capitalize Each Word
- Split Column by Delimiter
- Text Before Delimiter
- Custom Column
- Add Suffix
- Replace Errors
- Merge Columns
- Data Type Conversion
- Date Format Validation
